\begin{abstract}
Agent workflows are often compared by call count or a loose completion limit.
Neither measure answers the practical question: which architecture makes the
best decision when every prompt and completion must fit inside the same budget?
This paper defines a controlled experiment in mortgage adjudication using the
official 2024 Home Mortgage Disclosure Act data. We convert predecision
application fields into a transparent research policy with four outcomes:
approve, conditional review, deny, and manual review. Historical lender action
remains a descriptive outcome, not ground truth. Each application also receives
a counterfactual twin that changes one monitoring-only demographic field while
holding the financial evidence and policy label fixed. The primary study holds
GPT-5.4-mini fixed while comparing a monolith, plan-and-retrieve, a specialist
committee, a fixed compliance guardrail, and adaptive guarded routing at four
calibrated total-token budgets. A separate ablation studies selective escalation
to Claude Sonnet 4.6. The primary unit is the source application, and success
requires a correct decision on both twins. This artifact freezes the dataset,
prompts, gateway preflight, budget accounting, metrics, and analysis before the external gateway
run. It reports no model-performance result yet.
\end{abstract}
