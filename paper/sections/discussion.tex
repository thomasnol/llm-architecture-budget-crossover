\section{Interpretation Rules and Limitations}

The generated conclusion is determined by the frozen labels, not by editorial
preference. \nolinkurl{strict_crossover_confirmed} means both directional exact
tests passed after endpoint reversal. \nolinkurl{threshold_benefit_only} means
high-budget superiority passed but the low endpoint did not establish harm.
\nolinkurl{low_budget_harm_only} establishes only the low component.
\nolinkurl{endpoint_reversal_not_confirmed} describes point estimates with
insufficient directional evidence. \nolinkurl{no_directional_pattern} supports
neither conditional component. Non-significance is not equivalence, a
conditional crossing interval is not an unconditional interval, and equality
is never relabeled as a crossover.

The primary datasets are financial question-answering benchmarks, not a census
of deployed financial work. The document filters improve lineage and
independence but change the target population. Gold derivations can be
executable while still reflecting annotation choices. The checker is
label-blind, so it can reject unsupported arithmetic but cannot guarantee a
correct interpretation. All systems use the same model; correlated errors are
therefore expected and are part of the architecture estimand.

The hard budget measures gateway-reported prompt and completion tokens. Tool
calls, CPU time, wall time, latency, and cost are separate telemetry rather than
hidden additions to the token intervention. Exact tokenizer availability is a
deployment prerequisite. If the gateway cannot provide the frozen tokenizer
identity and prompt count, the experiment stops instead of estimating tokens
from characters.

FinanceComplexQA remains exploratory until every boundary passes. Even then,
its scorer, source structure, and retrieval behavior differ from the primary
datasets, so it is not confirmation evidence. The deterministic offline fixture
is also not evidence: it exists to prove that incomplete grids, failed gates,
hash mismatches, scripted responses, and protocol violations cannot generate
empirical prose.

\section{Current Conclusion}

No empirical conclusion is available in this protocol-only build. Historical
repository outputs do not satisfy the present estimand or artifact gates. The
conditional hypothesis is currently neither supported nor cleanly falsified.
The next valid conclusion, including a null or negative conclusion, must come
from a complete validated manifest whose preflight and pilot-gate hashes match
and whose exact expected grid contains authoritative protocol-valid usage.
