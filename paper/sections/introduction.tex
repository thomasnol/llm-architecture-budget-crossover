\section{Question and Conditional Hypothesis}

Test-time computation is useful only when its mechanism earns the resources it
consumes. Planning can improve evidence selection, a checker can reject an
unsupported calculation, and repair can recover a valid answer. Yet every added
prompt repeats instructions and evidence, every candidate reserves completion
space, and coordination can crowd out the very search it was intended to
improve. Prior work shows that additional test-time compute can help, but that
its best allocation depends on task difficulty \citep{snell2024testtime}.
Self-correction is also unreliable without an informative external signal
\citep{kamoi2024selfcorrection}. These observations motivate a conditional
rather than universal claim about agent structure.

Let $D_b$ be the paired accuracy difference
\texttt{verified\_search} minus \texttt{monolith} at budget tier $b$. The
confirmatory hypothesis is
\begin{equation}
H_1: D_{\mathrm{low}}<0 \quad\text{and}\quad D_{\mathrm{high}}>0.
\label{eq:hypothesis}
\end{equation}
The low-budget component asks whether coordination overhead hurts when resources
are scarce. The high-budget component asks whether planned retrieval and
label-blind verification help once their mandatory actions fit. Both directional
components must pass. A positive high-tier effect alone is a threshold benefit,
not a crossover. A zero difference at any endpoint is not a crossing.

The design separates three questions that are often conflated. First, does extra
inference structure change correctness under a hard resource intervention?
Second, does the intervention actually change realized actions and token use?
Third, does any observed gain dominate simpler alternatives on tokens, cost, or
latency? The confirmatory estimand addresses the first question for FinQA and
TAT-QA. Mechanism and resource tables address the second. Resource-specific
Pareto estimates address the third. FinanceComplexQA is reported separately as
an exploratory diagnostic domain.
